# KENZ MARKET NOKOS — Legal Pages

Static HTML pages for GitHub Pages:
- `index.html`
- `terms.html`
- `privacy.html`
- `style.css`

## Before publishing
1. Replace `[REPLACE WITH YOUR BUSINESS EMAIL]`.
2. Replace `[REPLACE WITH YOUR DISCORD SERVER INVITE OR SUPPORT URL]`.
3. Review the Privacy Policy and remove or adjust any data category that does not match your real operations.
4. Confirm your actual refund, replacement, retention, and support practices match the wording.
5. This is a general template, not legal advice.

## GitHub Pages
Create a public repository named `kenz-market-legal`, upload all four files to the repository root, then open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.

After publishing, URLs will be:
- `https://YOUR-GITHUB-USERNAME.github.io/kenz-market-legal/`
- `https://YOUR-GITHUB-USERNAME.github.io/kenz-market-legal/terms.html`
- `https://YOUR-GITHUB-USERNAME.github.io/kenz-market-legal/privacy.html`

GitHub Pages may take a few minutes to publish.
